# Как открыть сайт VeloCraft

## Способ 1 — двойной клик (проще всего)
Откройте папку **`preview`** и дважды кликните **`index.html`** — сайт откроется в браузере.
Ничего устанавливать не нужно. (Шрифты подгружаются из интернета; без сети сайт откроется с запасными шрифтами.)

> Файл `preview/index.html` — собранная копия сайта. Он обновляется командой из «Способа 3».

## Способ 2 — через VS Code
1. Откройте папку проекта: **File → Open Folder**.
2. Установите расширение **Live Server** (Ritwick Dey): вкладка Extensions (Ctrl+Shift+X) → поиск «Live Server» → Install.
3. В проводнике VS Code правый клик на **`preview/index.html`** → **Open with Live Server**. Сайт откроется в браузере и будет обновляться сам.

Без расширений: правый клик на `preview/index.html` → **Reveal in File Explorer / Finder** и откройте файл двойным кликом.

## Способ 3 — режим разработки (для правки кода)
Нужны Node.js 20+ и pnpm (`npm i -g pnpm`). В терминале VS Code (Ctrl+`) из корня проекта:

```bash
pnpm install
cd artifacts/velocraft
PORT=5173 BASE_PATH=/ pnpm run dev          # macOS / Linux / Git Bash
# Windows PowerShell:
#   $env:PORT=5173; $env:BASE_PATH="/"; pnpm run dev
```
Откройте http://localhost:5173

Пересобрать файл для «Способа 1» после изменений:
```bash
cd artifacts/velocraft
pnpm run build:preview        # результат: preview/index.html
```
Боевая сборка для хостинга: `PORT=1 BASE_PATH=/ pnpm run build` → папка `artifacts/velocraft/dist/public`.
